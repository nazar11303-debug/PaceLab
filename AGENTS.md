# AGENTS.md — правила роботи в проєкті PaceLab

## 1. Межі робочої зони

- Працюй **ВИКЛЮЧНО** всередині директорії `PaceLab/`.
- Не звертайся до батьківських каталогів (`../`), робочого столу та системних папок.
- Усі шляхи — відносні від кореня проєкту; жодних абсолютних шляхів поза ним.

## 2. Python

- Запускати Python **тільки** через інтерпретатор віртуального середовища:
  `.venv\Scripts\python.exe`.
- Ніколи не використовувати глобальний `python`, `py` чи пакети системного Python.
- Встановлення залежностей: `.venv\Scripts\pip.exe install -r requirements.txt`.
- Запуск застосунку: `.venv\Scripts\python.exe -m uvicorn app.main:app --reload`
  (або подвійний клік по `start.bat`).

## 3. Файли та дані

- **Заборонено видаляти файли** (`Remove-Item`, `del`, `rmdir`, `rm`, `shutil.rmtree`).
- Застарілі або непотрібні файли **переносити в `_backup/`** (з датою у назві,
  напр. `_backup/2026-11-13_PaceLab.db`).
- Оригінальні завантаження — в `uploads/`; тимчасові файли (тести, чернетки) — в `_tmp/`.
- `PaceLab.db` — локальні дані користувача, не комітити й не бекапити в git;
  копії БД — лише в `_backup/`.
- Ніяких демо-даних у репозиторії: застосунок стартує з порожньою БД.

## 4. Git

- `checkpoint_stage1` — базовий чекпойнт проєкту.
- Перед великими змінами — окремий commit.
- Не комітити: `.venv/`, `PaceLab.db`, `uploads/*`, `_backup/`, `_tmp/`,
  `__pycache__/`, `docs/.chrome-profile/`.

## 5. Перевірка перед здачею

```powershell
# сервер (тимчасово)
.venv\Scripts\python.exe -m uvicorn app.main:app
# автотести в іншому терміналі
.venv\Scripts\python.exe tools\smoke_test.py
```

- Після тестів **зупинити сервер** — порт 8000 не залишати зайнятим.
- Тестові файли/БД після прогону переносити в `_backup/`, а не видаляти.
